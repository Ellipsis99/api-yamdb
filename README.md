# API YaMDb

Проект **YaMDb** собирает отзывы пользователей на произведения. Произведения делятся на категории («Книги», «Фильмы», «Музыка») и могут быть отмечены жанрами. На каждое произведение пользователи оставляют отзывы с оценкой, а из оценок формируется рейтинг. К отзывам можно писать комментарии.

Это REST API проекта (без фронтенда), сделанный командой из трёх разработчиков.

## Технологии

- Python 3.12
- Django 5.1
- Django REST Framework
- Simple JWT (аутентификация по токену)
- django-filter

## Как запустить проект

Клонировать репозиторий и перейти в него:

```bash
git clone https://github.com/Ellipsis99/api-yamdb.git
cd api-yamdb
```

Создать и активировать виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Выполнить миграции:

```bash
cd api_yamdb
python manage.py migrate
```

Запустить сервер:

```bash
python manage.py runserver
```

API будет доступно по адресу `http://127.0.0.1:8000/api/v1/`. Документация (ReDoc) — `http://127.0.0.1:8000/redoc/`.

## Загрузка тестовых данных

В проекте подготовлены CSV-файлы с тестовым контентом.

Для заполнения базы данных выполните команду:

```bash
python manage.py load_csv_data
```

Внимание! 
Команда полностью очищает базу данных.

## Пользователи и аутентификация

Аутентификация — по JWT-токену. Регистрация двухшаговая: пользователь получает код подтверждения на e-mail, а затем обменивает его на токен.

### Роли

- **Аноним** — может только читать.
- **Аутентифицированный пользователь (`user`)** — может читать всё, оставлять отзывы и комментарии, ставить оценки, редактировать и удалять свои отзывы и комментарии.
- **Модератор (`moderator`)** — те же права плюс возможность удалять и редактировать любые отзывы и комментарии.
- **Администратор (`admin`)** — полные права на управление контентом и пользователями.

### Регистрация нового пользователя

Отправить `username` и `email`:

```
POST /api/v1/auth/signup/
```

```json
{
    "email": "user@example.com",
    "username": "new_user"
}
```

На указанный e-mail придёт код подтверждения (в режиме разработки письмо выводится в консоль).

### Получение JWT-токена

```
POST /api/v1/auth/token/
```

```json
{
    "username": "new_user",
    "confirmation_code": "string"
}
```

В ответе придёт токен, который нужно передавать в заголовке:

```
Authorization: Bearer <token>
```

### Работа со своей учётной записью

```
GET   /api/v1/users/me/     — получить свои данные
PATCH /api/v1/users/me/     — изменить свои данные (роль менять нельзя)
```

### Управление пользователями (только администратор)

```
GET    /api/v1/users/                — список пользователей
POST   /api/v1/users/                — создать пользователя
GET    /api/v1/users/{username}/     — пользователь по username
PATCH  /api/v1/users/{username}/     — изменить пользователя
DELETE /api/v1/users/{username}/     — удалить пользователя
```

## Категории и жанры

- Полная CRUD-логика для категорий и жанров (только администратор может создавать и удалять).
- Поиск по названию (`?search=`).
- Пагинация.

## Произведения

- Создание, чтение, обновление, удаление произведений (только администратор может изменять).
- Фильтрация по категории (`?category=`), жанру (`?genre=`), году (`?year=`) и названию (`?name=`).
- Рейтинг произведения (средняя оценка из всех отзывов) возвращается в ответе.
- Пагинация.

### Примеры запросов

**POST** `/api/v1/titles/` — создать произведение

В запросе жанры и категория передаются **строками (slug)**:

```json
{
  "name": "Матрица",
  "year": 1999,
  "description": "Фильм про Нео",
  "genre": ["fantastika", "boevik"],
  "category": "filmy"
}
```

В ответе жанры и категория возвращаются **объектами** (с `name` и `slug`):

```json
{
  "id": 1,
  "name": "Матрица",
  "year": 1999,
  "rating": 8,
  "description": "Фильм про Нео",
  "genre": [
    {"name": "фантастика", "slug": "fantastika"},
    {"name": "боевик", "slug": "boevik"}
  ],
  "category": {"name": "Фильмы", "slug": "filmy"}
}
```

**GET** `/api/v1/titles/{titles_id}/` — получить одно произведение

Ответ — такой же, как при создании (с объектами жанров и категории, включая `rating`).

## Отзывы, комментарии и рейтинг

### Отзывы

Отзыв привязан к произведению. Один пользователь может оставить **только один отзыв** на конкретное произведение. Оценка (`score`) — целое число от 1 до 10. Рейтинг произведения считается как средняя оценка по всем его отзывам.

```
GET    /api/v1/titles/{title_id}/reviews/               — список отзывов
POST   /api/v1/titles/{title_id}/reviews/               — добавить отзыв
GET    /api/v1/titles/{title_id}/reviews/{review_id}/   — отзыв по id
PATCH  /api/v1/titles/{title_id}/reviews/{review_id}/   — изменить отзыв
DELETE /api/v1/titles/{title_id}/reviews/{review_id}/   — удалить отзыв
```

Пример запроса на создание отзыва:

```json
{
    "text": "Отличное произведение!",
    "score": 9
}
```

### Комментарии

Комментарии оставляются к конкретному отзыву.

```
GET    /api/v1/titles/{title_id}/reviews/{review_id}/comments/              — список
POST   /api/v1/titles/{title_id}/reviews/{review_id}/comments/              — добавить
GET    /api/v1/titles/{title_id}/reviews/{review_id}/comments/{comment_id}/ — по id
PATCH  /api/v1/titles/{title_id}/reviews/{review_id}/comments/{comment_id}/ — изменить
DELETE /api/v1/titles/{title_id}/reviews/{review_id}/comments/{comment_id}/ — удалить
```

Пример запроса на создание комментария:

```json
{
    "text": "Полностью согласен с отзывом."
}
```

### Права на отзывы и комментарии

- Читать — могут все, включая анонимов.
- Создавать — только аутентифицированные пользователи.
- Редактировать и удалять свой отзыв/комментарий — автор.
- Редактировать и удалять любой отзыв/комментарий — модератор и администратор.
